## 同流程规模估算与 48 小时预算

| 场数 | 按实测平均成本线性估算 | 按观察到的单场最小／最大成本外推 |
| --- | ---: | ---: |
| 1,000 | 4.77 小时 | 4.16–5.46 小时 |
| 10,000 | 47.74 小时 | 41.62–54.60 小时 |

这些是 16 场并发负载下的工程估算；范围不是置信区间，也不能保证 10,000 场在 48 小时内完成。
本次已设置 `max_wall_seconds=172800`，但 275 秒即完成，因此没有触发预算暂停。
冻结版本在开始下一场前检查预算；达到预算后会在完整对局及验证完成的边界暂停，
正在进行的一局会先完成，实际墙钟可能略超 48 小时。同配置重跑会复验已完成记录后续采。

后续可优先评估四个 Agent／worker 在一次采集内跨局复用，并保留严格 reset 和身份核验。
当前未拆分 reset 中各个子环节，66.17% 不等于可节省比例；尚未实施或测量任何优化收益。
生命周期变更须另行冻结、验证，再决定是否用于教师数据。
